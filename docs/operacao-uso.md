# Operação e Uso

Fluxo básico de uso

1. Acesse a aplicação e faça login com credenciais válidas.
2. No dashboard, visualize a lista de ativos e filtros disponíveis.
3. Para cadastrar um ativo, preencha o formulário com os dados obrigatórios (identificador, responsável, departamento, datas, status).
4. Para editar ou excluir, use as ações correspondentes na listagem.
5. Para operações que alteram dados em massa, utilize importação/exportação se disponível no repositório.

Boas práticas

- Use contas de usuário separadas para testes e produção.
- Faça backups do banco antes de operações de massa.
- Não copie senhas ou tokens em arquivos de documentação.
