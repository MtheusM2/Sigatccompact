# Roadmap

Próximos passos técnicos

1. Separar API e UI com mais clareza, sem alterar o fluxo atual baseado em sessão.
2. Implementar permissões por função (admin/usuário).
3. Avaliar futuramente se a migração para Bearer Token ainda faz sentido para a entrega final.

Melhorias de segurança

- Implementar rotação de chaves e armazenamento seguro de secrets.
- Adicionar logs de auditoria e monitoramento.

Melhorias de usabilidade

- Refinar dashboard e filtros avançados.
- Melhorar importação/exportação e validação de arquivos.

Melhorias acadêmicas / TCC

- Consolidar documentação ABNT (se aplicável).
- Preparar roteiro e slides para apresentação.
