<details open>
<summary><strong>🏛️ Governança e Gestão de TI</strong></summary>

| Termo | Definição |
|-------|-----------|
| **Governança de TI** | Estruturas, processos e mecanismos que garantem que a TI sustente e estenda a estratégia da organização. Envolve direção, avaliação e monitoramento (ISO/IEC 38500). |
| **Gestão de TI** | Planejamento, construção, execução e monitoramento de atividades operacionais de TI, alinhadas à direção definida pela governança. |
| **Alinhamento Estratégico** | Grau de integração entre a estratégia de TI e a estratégia de negócio da organização. |
| **Compliance** | Conformidade com leis, regulamentos, normas e políticas internas aplicáveis. |
| **Maturidade** | Nível de evolução de um processo, medido em escalas de 0 (inexistente) a 5 (otimizado). |
| **Stakeholder** | Parte interessada que afeta ou é afetada pelas decisões do projeto (usuários, gestores, diretoria, fornecedores). |

</details>

<details>
<summary><strong>📘 ITIL v4</strong></summary>

| Termo | Definição |
|-------|-----------|
| **ITIL** | Information Technology Infrastructure Library — boas práticas para gerenciamento de serviços de TI, versão 4. |
| **SVS (Service Value System)** | Modelo que descreve como componentes da organização trabalham juntos para gerar valor por meio de serviços. |
| **Cadeia de Valor de Serviço** | 6 atividades: Planejar, Engajar, Design & Transição, Obter/Construir, Entregar & Suportar, Melhorar. |
| **Serviço** | Meio de cocriação de valor ao facilitar resultados que o cliente deseja, sem assumir custos e riscos específicos. |
| **Incidente** | Interrupção não planejada ou redução na qualidade de um serviço de TI. |
| **Problema** | Causa raiz (real ou potencial) de um ou mais incidentes. |
| **Mudança** | Adição, modificação ou remoção de algo que possa afetar serviços de TI. |
| **Requisição de Serviço** | Solicitação que faz parte da entrega normal de serviço (reset de senha, novo acesso). |
| **SLA (Service Level Agreement)** | Acordo entre provedor e cliente com metas de nível de serviço. |
| **OLA (Operational Level Agreement)** | Acordo interno entre áreas que suporta o cumprimento dos SLAs. |
| **CMDB** | Banco de dados de itens de configuração e seus relacionamentos. |
| **CI (Item de Configuração)** | Componente gerenciado para entrega de serviço (hardware, software, documento). |
| **Service Desk** | Ponto único de contato para registro e acompanhamento de incidentes e requisições. |
| **Catálogo de Serviços** | Lista de serviços de TI disponíveis com descrições, prazos e responsáveis. |
| **Base de Conhecimento** | Repositório de erros conhecidos e soluções de contorno. |
| **Melhoria Contínua** | Prática recorrente de identificar e implementar melhorias. |

</details>

<details>
<summary><strong>📗 COBIT 2019</strong></summary>

| Termo | Definição |
|-------|-----------|
| **COBIT** | Control Objectives for Information and Related Technologies — framework de governança e gestão de TI da ISACA. |
| **Cascata de Objetivos** | Traduz necessidades dos stakeholders → objetivos corporativos → objetivos de alinhamento → objetivos de governança/gestão. |
| **Domínios** | EDM (Evaluate, Direct, Monitor), APO (Align, Plan, Organize), BAI (Build, Acquire, Implement), DSS (Deliver, Service, Support), MEA (Monitor, Evaluate, Assess). |
| **Habilitadores** | 7 fatores: princípios/políticas, processos, estruturas, cultura, informação, serviços/infraestrutura, pessoas/competências. |
| **RACI** | Responsible (executa), Accountable (aprova), Consulted (opinião), Informed (informado). |
| **Design Factors** | Fatores contextuais que influenciam o design do sistema de governança. |

</details>
